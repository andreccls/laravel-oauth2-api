# laravel-oauth2-api (English summary)

A **reference / example project** (not a production product) showing a **real OAuth2 server** on **Laravel 13 + Passport 13**,
API-only, fast on **Octane (RoadRunner)**. Full documentation is in Portuguese: [README.md](README.md),
[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), [docs/adr](docs/adr).

## What you get

- **OAuth2 grants:** authorization code + **PKCE**, **client credentials**, **refresh token** (rotating, single use).
  Password grant is deliberately not offered (removed in OAuth 2.1).
- **Scopes** enforced per route (`oauth:tasks:read`, `oauth:tasks:write`); `write` does not imply `read`.
  Insufficient scope -> 403, bad/expired/revoked token -> 401, over the limit -> 429, all as RFC 9457 `problem+json`.
- **Protected resource:** `tasks` CRUD (+ nested items) with Form Requests, API Resources, pagination, per-owner isolation.
  Both user tokens and machine (client-credentials) tokens work; each owner sees only its own data.
- **Token introspection / revocation:** `GET /api/me`, `POST /api/oauth/revoke`; scheduled `passport:purge`.
- **Performance:** Octane + RoadRunner, cached config/routes/events, Redis rate limiting **per OAuth client**, indexes checked
  with `EXPLAIN`, eager loading with an N+1 test, `ETag`/304. Measured on a local M3 (ApacheBench, c=16, 5 interleaved runs):
  Octane **median 505 req/s** vs php-fpm **361 req/s** on the protected list endpoint (p50 26 ms vs 35 ms). It is a noisy
  local benchmark: indicative only.
- **Quality:** 59 tests (PHPUnit), **100 % line coverage** as a gate (PCOV), PHPStan level 8 (Larastan), Pint; the suite also
  passes against MySQL 8.4. OpenAPI 3.1 generated by Scramble and kept honest by a test.

## Run it (Docker only, no PHP on the host)

```bash
make up        # Octane + MySQL 8.4 + Redis + scheduler -> http://localhost:8088
make demo      # seeds a demo user and walks through every OAuth2 flow with curl
make test      # all tests (SQLite in memory)        make test-mysql   # same suite on MySQL 8.4
make lint      # Pint + PHPStan level 8              make coverage     # fails below 100 % of lines
make bench     # php-fpm vs Octane                   make down | clean
```

All credentials in `docker-compose.yml` / `.env.example` are **development-only**. Passport keys are generated at container
start and are never committed.

## Known limitations (see the Portuguese README for the full list)

Revocation checks hit MySQL on every request (Passport behaviour); no per-client scope allow-list; no client-management
endpoint; JSON-only consent screen; the Redis/Lua limiter path is exercised by the demo/benchmark, not by automated tests;
Swoole/FrankenPHP not tried; the GitHub Actions workflow was not executed in the original environment.
